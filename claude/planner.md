Preciso que você crie uma aplicação frontend idêntica ao figma informado. Essa aplicação não será conectada a nenhum backend, ao invés disso deve salvar informações relevantes do localstorage do cliente.

Crie uma aplicação escalável, leve, elegante e organizada. Sempre que possível, separe os elementos em componentes escaláveis e reaproveitáveis.

A paleta de cores deve ser coesa e deve seguir um padrão. Crie variáveis para elas, de modo que seja possível alterar todas as cores do projeto sem complicação.

Para os ícones pode usar a lib lucide-icons https://lucide.dev/guide/react/getting-started

Por enquanto gostaria que você criasse apenas a primeira página do fima (a que está com o frame chamado "01 - mapa inicial da jornada)

Elementos obrigatórios:
Menu lateral com o nome do projeto com componente de progresso e uma lista com todos os tópicos do projeto (pode mockar os dados iguais estão no figma, se achar necessário)

Deve implementar uma lógica de progressão. De modo que só será possível entrar na segunda página caso tenha passado pela primeira. Ao passar por uma página, deve atualizar o componente de progresso.

A página inicial vai ser a "/" do projeto.
